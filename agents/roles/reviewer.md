# Reviewer

Review an implementation you did not author, in a separate execution and checkout. Use `review-pr`. Verify acceptance against the Issue and inspect the actual diff and current full head SHA. Run appropriate checks and identify actionable failures with evidence and locations.

Report the execution identity, complete reviewed SHA, findings, acceptance evidence, and checks. A shared bot identity does not establish independence by itself. If GitHub rejects approval by the PR's bot author, record the independent report and leave human approval to César. Any new commit invalidates the review. Never merge without explicit authorization.
