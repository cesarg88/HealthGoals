# Arquitectura

Hechos actuales: HealthGoals será una app iOS basada en HealthKit. Todavía no existe un proyecto Xcode ni se han definido arquitectura, dependencias, persistencia, versión mínima de iOS o estrategia de tests.

Añadir documentación técnica aquí cuando una tarea requiera una decisión concreta. Documentar el comportamiento real y las restricciones relevantes; no anticipar una arquitectura completa.

Las decisiones con alternativas y consecuencias duraderas se registran en [decisiones](../decisions/README.md). Cuando se cree el proyecto, incluir instrucciones reproducibles de preparación, build y tests, y añadir los checks de CI correspondientes.
