# Arquitectura

Hechos actuales: HealthGoals será una app basada en HealthKit con mínimo iOS 26 e iPadOS 26, para iPhone e iPad en todas las orientaciones, según la [compatibilidad confirmada por César](../product/mvp-scope.md#2-usuario-objetivo). Todavía no existe un proyecto Xcode ni se han definido arquitectura, dependencias, implementación de persistencia o estrategia de tests. La cobertura de dispositivos y orientación requerirá evidencia de validación y registro de las limitaciones técnicas reales de plataforma.

Añadir documentación técnica aquí cuando una tarea requiera una decisión concreta. Documentar el comportamiento real y las restricciones relevantes; no anticipar una arquitectura completa.

Las decisiones con alternativas y consecuencias duraderas se registran en [decisiones](../decisions/README.md). Cuando se cree el proyecto, incluir instrucciones reproducibles de preparación, build y tests, y añadir los checks de CI correspondientes.
